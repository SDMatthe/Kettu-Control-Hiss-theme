# Kettu-Control-Hiss-theme

Equicord-compatible port of the original Kettu *Control Hiss* theme.

## Files

- `kettu-control-hiss.theme.css` — Equicord/Discord desktop theme file.
- `kettu-control-hiss.json` — original legacy mobile-style JSON theme kept for reference.

## Install on Equicord

1. Open Equicord settings.
2. Go to **Equicord > Themes**.
3. Click **Open Themes Folder**.
4. Copy `kettu-control-hiss.theme.css` into that folder.
5. Enable **Kettu Control Hiss** in the theme list.

## Notes

The visual design (accent colors, dark background, and Hiss pattern background) is preserved from the original theme while using Equicord-compatible CSS variables and metadata.
